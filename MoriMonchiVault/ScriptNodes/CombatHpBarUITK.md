# CombatHpBarUITK.cs

**Ruta:** `UI/CombatHpBarUITK.cs`

**Responsabilidad:** Barra de HP UITK para un lado del combate (A o B). Se suscribe a `CombatVisualEvents` para mostrar nombre inicial y animar el fill del HP con lerp configurable. Interpola suavemente el porcentaje de HP en cada daño recibido.
