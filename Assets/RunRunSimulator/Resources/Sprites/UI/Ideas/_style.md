# _style — dirección de arte compartida (se antepone a TODOS los prompts)

El script `gen-image.ps1` lee el blockquote bajo `## Style` y lo pone **antes** del prompt de cada pieza. Editá acá para mover el estilo de todo el set de una vez.

## Style

> Low-poly PS2-era video game UI asset, early-2000s console interface aesthetic to match a low-poly game whose characters look like PlayStation 2 models. Flat shading with simple hard-edged gradients, chunky geometric shapes, low detail, slightly low-resolution with mild dithering. Clean and MINIMAL, deliberately NOT busy, NOT overloaded, no clutter, lots of empty space. Stylized, not photorealistic: no heavy bloom, no realistic neon-tube glass, no tiny intricate details. Cohesive 1980s synthwave palette only: cyan (#00DCFF), magenta (#FF46B4), deep purple-black background (#10121C). Consistent medium line weight across the whole set so every piece reads as the same family. Flat solid colors over gradients where possible.
